PRIVACY English

This game collects no personal data.

· No account, no name, no e-mail, no location.
· Your save stays on your device (user://save.cfg) and is never sent to a server.
· No ad network, no analytics, no third-party tracker.
· On launch the game downloads an UPDATE file (version number and store link). No information about you is sent with that request.
· If the game closes unexpectedly, an ERROR REPORT may be sent to the developer. It contains only: the error text, game version, operating system and device model, game language, your in-game level and session length. No name, e-mail, location, device identifier or save data is sent.
· Delete the game and the save goes with it.

Questions: wtfpiletisim@gmail.com
